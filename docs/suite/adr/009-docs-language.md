# ADR-009. 문서 언어

- 상태: 결정됨
- 날짜: 2026-11-01 (2026-10-31 제안을 뒤집음)
- 범위: Bumpist Suite 전체

## 결정

다섯 저장소의 `README.md`는 한국어로 쓰고, 이것이 기준이다. 영어는 필요해질 때 `README.en.md`로 더하고, 한국어판보다 늦을 수 있다는 안내를 맨 위에 둔다.

이미 영어로 쓴 내부 문서(예: bumpist-ship의 `RELEASING.md`)는 그대로 둔다. 새 사용자 문서는 한국어로 쓴다.

## 이유

- 지금 독자는 한국어 사용자이고, 비개발자도 README만 보고 이해할 수 있어야 한다.
- 두 언어를 같은 수준으로 유지하는 비용이 1인 메인테이너에게 크다. 번역이 늦으면 영어판이 틀린 문서가 된다.

## 고려한 대안

- 영어 기본 + 한국어 병기 (2026-10-31 제안): 해외 노출에는 유리하지만, 지금 독자와 유지 비용에 맞지 않았다.

## 후속

해외 사용자가 생기면 영어판을 다시 검토한다. 그때는 한국어판을 바꿀 때 영어판도 같은 PR에서 고치는 규칙을 함께 정한다.
